# Security

Chiltepin renders Markdown you control into static HTML and SVG. It runs no code from documents, contacts no network at render time, and the CLI writes only where you point it.

If you find a vulnerability (for example, HTML injection through a block field, or a path traversal in `chiltepin build`), email the maintainer through the address on the npm package page or open a private security advisory on GitHub. Please do not open a public issue for it. You will get a reply within a week, and a fix release with credit unless you prefer otherwise.
